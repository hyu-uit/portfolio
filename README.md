# My Portfolio - Three.js Exploration

Welcome to my portfolio! This project is an interactive 3D website where I explore and learn about Three.js. It showcases my ability to work with modern web technologies, adapt existing projects, and improve them using TypeScript.

## 👨‍💻 About Me

I am a passionate Frontend Developer with experience in building modern web applications using React, React Native, TypeScript, and various web and mobile technologies. I enjoy working with 3D graphics and animations, exploring new frameworks, and creating interactive user experiences. This portfolio represents my dedication to continuous learning and improvement in the field of web development.

## 🚀 About the Project

This project is based on a tutorial by [JavaScript Mastery](https://www.youtube.com/watch?feature=shared&v=0fYi8SGA20k). However, I made several modifications to enhance and personalize the experience:

- Converted the project from JavaScript to **TypeScript** for better type safety and maintainability.
- Customized some parts to align with my personal style and learning objectives.
- Deployed the final version on **Firebase**: [Live Demo](https://huynhthevi-fe.web.app/)

## 🎨 Features

- **Three.js integration** for rendering 3D objects
- **TypeScript** for improved code quality
- **Responsive Design** to ensure a seamless experience across different devices
- **Optimized Performance** with better asset management
- **Smooth Animations** using GSAP for interactive user experience

## 📚 Technologies Used

- **Three.js** - 3D graphics library
- **React** - Frontend framework
- **Vite** - Fast development build tool
- **GSAP** - Animation library
- **TypeScript** - Typed JavaScript
- **Firebase** - Hosting and deployment

## 🛠 Installation & Setup

If you want to explore or contribute to this project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/hyu-uit/portfolio.git
   ```
2. Navigate to the project folder:
   ```sh
   cd repo-name
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173/` (or the port Vite provides).
